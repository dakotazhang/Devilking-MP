# 安装与使用

口袋蕾姆是 iOS 16.1+ 的原生服务器管理工具，支持多台 qBittorrent/Transmission、分组状态统计与 MoviePilot 搜索订阅。当前版本为 [2.0.3](https://github.com/dakotazhang/Devilking-MP/releases/tag/v2.0.3)，补齐下载和做种卡片的已有分类、标签及使用说明；保留大任务量切页优化、关于置顶和连接配置置底。


## 安装与升级

无签名 IPA 可由支持该系统的 TrollStore 安装，或使用自己的有效开发者/企业证书重签。项目不包含证书或描述文件。保持原 Bundle ID `top.devilkkkkk1.DevilkingMP`；覆盖安装能否保留钥匙串与资料还取决于签名身份和安装方式，建议在自己的电脑安全保存一份私密连接备份。

最低部署版本不等于每台 iPhone 都已验收。本轮需要在 iOS 16.1 真机复核顶部按钮、搜索键盘、详情弹层及后台返回布局；也需要另验自己的证书安装和外网 VPN。

第一次运行允许本地网络访问。外出先连接现有 WireGuard 等家庭 VPN，再使用相同内网入口。

## 连接资料

进入“设置 → 服务器设置”，分别填写服务根地址和登录资料：

- qBittorrent：WebUI 账号与密码，可添加多台并分别命名。
- Transmission：已有 RPC Basic 认证账号，可添加多台。
- MoviePilot：账号登录 JWT 或 X-API-KEY。
- Emby：旧连接配置继续兼容，本版没有独立片库标签页。

也可在电脑本地填写 [v2 连接模板](../examples/connection.v2.example.dkmp)，经自己的受保护通道传给手机，在设置底部“连接配置”导入。它用于批量填写连接资料，不是下载入口；手动逐台设置请用“服务器设置”。qB/TR 没有固定槽位限制；MoviePilot 与旧 Emby 各保留一个。旧 v1 模板继续兼容。

导入文件含密码。导入后登录资料进入 `WhenUnlockedThisDeviceOnly` 钥匙串，不同步 iCloud；请删除手机“文件”中的临时副本。普通配置和订阅待核对记录不存密码。不要上传真实连接文件或将其放入公开安装包。

HTTP 仅允许明确内网地址，外部地址要求有效 HTTPS。地址不能嵌入用户名、密码、查询 Token 或片段；凭据不随跨域重定向转发。

## 页面

| 页面 | 功能 |
| --- | --- |
| 状态表 | 下载器上传/下载速率、任务状态计数、目录剩余空间、连接和采样时间 |
| 下载器 | 按全部、分组或独立 qB/TR 查看，任务搜索、分类/标签/状态筛选、校验进度；授权后的单项启停与上传限速 |
| 发现 | “影视”推荐、片名搜索与默认规则订阅；“PT资源”选站搜索、查看种子并确认下载 |
| 订阅 | 已有电影/剧集追订、进度与状态筛选；授权后的单条暂停/恢复 |
| 设置 | 关于、服务器、分组、确认下载器身份、预设目录、刷新频率、角色背景、主题/语言/字体、状态表模块及操作保护 |

Emby 旧连接仍可保存并打开原管理页面。视频播放使用自己已有的播放器或 Emby 客户端。

## 在外订阅一部作品

1. 接通家庭 VPN，在“发现”浏览推荐或搜索片名。
2. 打开详情，核对名称、年份、类型与简介。电视剧须明确选择一季；季 0 表示特别篇。
3. 只读状态可以查看资料。准备提交时，在设置关闭全局只读锁，并启用 MoviePilot 的操作权限。
4. 点击订阅后再次核对作品与季号，再确认本次提交。
5. 到“订阅”页查看结果。已有订阅会拦截重复添加。

**新增订阅会让 MoviePilot 按现有站点、质量、过滤和下载器规则自动搜索，并可能下载匹配资源。** 手机不更改服务器默认规则；需要复杂过滤或路径设置时使用 MoviePilot 原页面。

片名搜索和推荐读取只查询影视元数据，不触发站点资源搜索或下载。订阅暂停只暂停后续自动调度，不能撤销已经接受的搜索或下载。

发现页跟随当前 MP 用户启用的推荐栏目和可用媒体来源，不固定为少数榜单。影视详情与订阅海报通过自己的 MoviePilot 加载；图片读取失败时可点击“重试海报”，不需要重新提交订阅或下载。

## 从已连接 PT 站点挑选种子

1. 首次使用先到“设置 → 确认下载器身份”，读取自己的 MP 下载器。如果 MP 的“主力下载器”和 App 的“家庭 qB1”实际是同一台，就选择“家庭 qB1”；TR 同理。两边名称和地址可以不同，关键是同一台下载器。不确定时保持“暂不选择”，此时不能发起下载。确认身份本身不会开始下载。
2. 在“发现”切换“PT资源”，选择已连接站点，输入片名或关键词后手动搜索。也可在影视详情选定作品和剧集季，再进入站点资源搜索。
3. 核对种子标题、站点、体积、做种人数，以及已知的免费期限与 HR 信息。查看结果不会添加下载任务。
4. 打开资源详情，明确选择下载器。目录默认沿用 MP 配置，也可为本次下载另选。
5. 准备下载时，须允许 MoviePilot 和目标下载器的操作，并关闭全局只读锁；目标仍受迁移保护约束。确认资源、下载器和目录后，只提交一次。
6. “下载请求已提交”表示 MP 接受任务；到下载器核对实际进度。它不代表已下载完整、通过校验或已满足站点做种要求。

手选具体种子由 MP 执行本次下载，完成后沿用 MP 现有目录映射、整理规则和媒体识别配置处理入库；不会自动建立持续追更订阅。影视订阅则交给 MP 按既有规则持续调度和自动选种。

实际下载可能计入站点下载量。免费期限和 HR 以实时站规为准，促销未知不等于免费或免 HR。搜索不会随输入或刷新频率自动执行。

超时、断线或结果未知时，先到 MoviePilot 或下载器只读核对。应用会保留待核对记录，重启、换目录或换下载器也不会自动重发同一资源。

## 下载目录适配自己的环境

不设置时沿用各自 MoviePilot 的默认下载目录。需要常用目录时，进入“设置 → 预设下载目录”，选择 MP 实际返回的目录作为本机偏好；资源详情仍可单次另选。其他用户使用自己的 MP 配置，无需修改代码或套用某个家庭的 NAS 路径。

本机选择不会改 MP 默认设置。切换 MP 连接时不沿用其他服务器的目录，目录移除后回到 MP 默认。更换 MP/下载器地址或移除实例后，须重新确认下载器身份；仅改显示名称不会解除匹配。

## 只读与迁移保护

全局只读锁默认开启，单服务管理许可也默认关闭。两者均允许时，才可以逐次确认对应写操作。每台下载器可独立标记迁移保护；原 qB1/TR 配置的保护继续保留，查看状态无需暂停校验。

本人发布、正在校验、等待校验的任务不能在 App 启停。没有删除数据、移动路径、重新校验、整库启停、强制开始或 Tracker 手动汇报功能。App 不会为了演练自动暂停家中的迁移或解除保护。

切后台、锁定、改连接或撤销权限会使尚未发出的旧确认失效。业务写失败不自动重试；TR 的有界 409 会话挑战与业务重试分别处理。

新增订阅发送前，会保存本机操作记录。超时、断线、业务结果不明或读回失败时，这个作品/季保持“待核对”，重新打开页面或重启 App 也不自动重发。刷新订阅或去 MoviePilot 核实；记录尚未确认时不要换一个入口重复添加。

## 状态表与数据解释

在线、离线、陈旧和未知分别显示。服务离线时，旧速率不作为当前健康数据相加；未取到数据不补成 0。

目录剩余空间是对应下载器默认目录的读取结果。多个下载器可能共用同一 NAS，不能把这些余量相加当作总容量。任务计数按客户端分别统计，同一文件跨站做种也可能对应多条任务。

qB“做种 · 暂无请求”不等于停止；TR 等待校验和正在校验分别显示。缓存站点数据的时间与 App 刷新时间不同；手机不会为状态表反复登录所有 PT 站点。

## 分类和标签怎么设置

在原 qBittorrent 中为任务设置分类或标签，在 Transmission 中为任务设置 labels；可以用 PT 站名，也可以保留用途、辅种和保护标记。回 App 刷新后，下载、做种和校验卡片都会显示原列表返回的文字，搜索可匹配相同内容。标签较多时进入任务详情查看完整原始内容。

App 不自动判断站点，不创建或修改标签，也不增加 Tracker/PT 查询去补齐站名。未设置或接口未返回的标签保持空白；标签不代表实际 Tracker 汇报成功或站内做种验收。

## 速度与刷新

上传限速用 Mbps：60 Mbps 约 7.5 MB/s，40 Mbps 约 5 MB/s。qB 使用 B/s，TR 使用 kB/s，提交后读取确认。各客户端限额相互独立，不自动控制全家总带宽。

在“设置 → 数据刷新频率”选择关闭、15、30、60、120 秒，默认 60 秒。状态表和当前可见的下载器页在前台按所选频率读取，也可下拉；进入页面也会读取一次。关闭自动刷新后仍可手动更新。自动更新不持续显示手动刷新转圈；影视推荐和 PT 资源搜索不会被定时重复执行。

普通状态表、任务列表与发现页读取有 22 秒总预算，超时后结束本轮并显示问题；手动站点资源搜索有较长的独立预算。发现页即使没有推荐或内容很少，也可以下拉刷新，并提供刷新/取消按钮。旧数据与读取失败分别显示，不把未知值补成 0。

海报按需加载并限制内存缓存。后台不常驻轮询，不承诺后台推送告警。开启应用锁后可用生物识别或设备密码解锁，切后台隐藏内容。

## 外观与状态表定制

设置支持跟随系统、浅色或深色主题；界面语言可选简体中文和 English (US)。影片名称、站点名称、服务端返回内容保留原文，部分服务错误也可能保持原文。

角色背景默认开启：状态表是蕾姆、下载器是爱蜜莉雅、发现是拉姆、订阅是碧翠丝、设置是艾姬多娜。进入“设置 → 角色背景”可一键关闭，主题、字体和其他偏好保持不变。背景插画随应用内置，无需联网获取；系统开启“降低透明度”时不显示装饰背景。

字体可跟随系统或放大，不缩小系统辅助功能文字。实时流量、任务监控、磁盘余量、服务器状态与入口可分别显示或隐藏。这些偏好只保存在本机，不改变下载任务或操作权限。

## 构建和验收

Mac 安装 Xcode 与 XcodeGen 后执行 `bash scripts/build-ios.sh all`。构建流程运行合成接口测试、只读/迁移保护回归和模拟器 UI 测试，再生成无签名 IPA。无需上传家庭账号或 Apple 证书。

自动化构建使用合成接口与模拟器，不操作真实服务器任务。合成测试、模拟器和用户真机反馈分别记录；构建与包摘要见对应 Release 的验证说明。
