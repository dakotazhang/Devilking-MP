# Artwork

Devilking MP管理 uses character-themed illustrations featuring Rem, Emilia, Ram, Beatrice and Echidna from *Re:Zero*. The five page backgrounds are bundled in the app's asset catalog as `PageRem`, `PageEmilia`, `PageRam`, `PageBeatrice` and `PageEchidna`. The existing Rem-themed AppIcon and BrandMark are unchanged.

Backgrounds can be disabled in Settings. They are also hidden when the system's Reduce Transparency option is enabled. No artwork service or remote image request is needed for these backgrounds.

Replace the themed artwork with your own assets when a different brand or license is needed. Maintained by [dakotazhang](https://github.com/dakotazhang).
