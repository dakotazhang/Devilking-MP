# Screenshot provenance

The existing `overview.png`, `downloaders.png`, `moviepilot.png`, `emby.png` and `settings.png` were captured from the 1.0.0 simulator build. They are historical references and do not demonstrate the 1.1.0 five-tab redesign or its status-bar fix.

New screenshots must come from an actual running simulator or physical device and be accompanied by the build/commit and test result. Synthetic UI-test content must be identified as a fixture, not as live household data. No real credentials, user media history, restricted URLs or account identities belong in public screenshots.
